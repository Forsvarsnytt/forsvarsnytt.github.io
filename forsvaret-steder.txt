# Hvert sted starter med ## Navn. Feltene:
#   posisjon:  breddegrad, lengdegrad (omtrentlig, sted eller kommune)
#   kommune:   kommunen stedet ligger i
#   gren:      hovedgren som bestemmer fargen: hæren, sjøforsvaret, luftforsvaret, heimevernet, spesialstyrker, cyber, utdanning, felles, nato
#   lenke:     Forsvarets side om stedet
#   - gren | Avdeling | kort forklaring (forklaringen kan stå tom)
#   tekst:     valgfri kort beskrivelse
#   søkeord:   ord som brukes for å finne nyheter om stedet (uten søkeord brukes navnet)
# Linjer som starter med # vises ikke.
